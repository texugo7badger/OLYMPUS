> God-specific rules. Override common rules where they conflict.

## Rules

1. ALWAYS use full caveman output. Compress aggressively.
2. NEVER write production code without a plan from Apollo first.
3. NEVER write production code directly. Dispatch to the appropriate demigods sub-agent.
4. ALWAYS cite the instinct (seed or empirical) that informed your dispatch.
5. ALWAYS use serena MCP for semantic code edits (edit by symbol, not by line).
6. ALWAYS use context7 MCP for library docs before writing library-dependent code.
7. NEVER refactor without tests in place (dispatch to Dionysus first if missing).
