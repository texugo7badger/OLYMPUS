## 1. Verdict

OLYMPUS is delivering real artifacts (63/84 hop attempts completed; the AIME site is live), but the product's measurement layer is not truthful:

1. The benchmark panel reports 4.4% success / 129 errors. All 130 error rows in dispatches.jsonl have **zero tokens and zero tool calls** — they are failed session starts, not failed work. Real work is 8 rows / 1.34M tokens. Hops are not recorded at all (they run in spawned processes).
2. The cost screen mixes three currencies (invoice, OpenCode step cost, heuristic list value) and calls the sum "spend"; the GO plan is a subscription and the app has no invoice feed, so "charged" is not knowable. The $12/5h "budget" is a per-model cap presented as a global one.
3. MCPs are globally spawned (16 in the current working tree, 107 tools) but the permission hook resolves every MCP call as **Apollo** (`getActiveScopeAndAgent("")`), so the gods actually running the hops cannot use their assigned MCPs. API keys written by the UI (`~/.olympus/api-configs.json`) are never injected into the Next/OpenCode spawn path.
4. The context indicator reads JSON session files; OpenCode 2.2.5 stores sessions in SQLite. It is structurally 0%.
5. The short-circuit gate has 2,999 evaluations and 0 hits; tag-similarity × confidence cannot reach 0.85 except on near-identical tag sets. It is not "cold start", it is effectively dead.
6. The campaign counters are derived from activity strings and differ from the hop-state file (0/17 vs 9/42). The ETA goes negative. A 30-minute heuristic marks pending hops as "running".
7. The live preview "Mark" cannot capture clicks inside a cross-origin iframe (the click never reaches the parent), and there are no back/forward controls. "Send to Athena" spawns a detached `opencode run` with no queue, no session, no element/component context.
8. Every god card says 0 dispatches for the gods that did the work (Athena 45 hops, Hephaestus 22, Persephone 7) because the card counts Symphony dispatches only; cost.jsonl shows 193 Hephaestus requests.
9. The Sync Map marks every "received" prompt as failed at process exit: 669 of 731 entries are "prompt died mid-flight".
10. The runtime auto-approves every permission in a hop (`permissionTimer` replies `once` to all asks) with no destructive-command gate. The AIME DB was wiped during the campaign; the restore cost a 25-minute hop. The exact command is not proven from the log (candidates: `prisma db push`, `db:seed`, a reset), but the missing gate is proven.
