# DESIGN.md Author

## The 9-Section Format

1. Overview
2. Tokens (color, typography, spacing, radius, shadow)
3. Typography
4. Spacing
5. Color
6. Components
7. Patterns
8. Motion
9. Accessibility

## Workflow

1. Extract tokens from Figma (via figma-developer-mcp)
2. Inventory components
3. Document patterns
4. Verify accessibility (WCAG-AA)
5. Write DESIGN.md to ~/OLYMPUS-VAULT/10_Design_Systems/<name>.md
